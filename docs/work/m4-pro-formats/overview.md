# M4 — Split archives, `.7z` creation + AES-256, GPL-safe `.rar` reading
Status: 진행 중
승인: 2026-11-27 (coordinator dispatch `ctx_8b002d42440e` is the approved spec)

## Context / 배경

Dandi M1–M3 shipped ZIP pack/unpack, 7z/TAR read, a desktop GUI and OS shell integration.
Users exchanging large folders over mail/messengers need split volumes, users who want
compression or encryption beyond WinZip AES need `.7z`, and Korean users still receive
`.rar` files. M4 adds all three without breaking the single security seam
(`ExtractionSink` + `sanitize_entry_path` + `SafetyBudget` + `create_new`) or the
`GPL-3.0-only` licence.

A previous worker left uncommitted core edits (split reader/writer, PKWARE split ZIP
writer, 7z writer, `rars`-based RAR reader). They compile and are reused after review;
this plan covers fixing what review found plus everything still missing (tests, CLI,
desktop, eval, docs).

RAR crate choice: `rars` 0.13 (Apache-2.0, pure Rust, `unsafe_code = "deny"`, RAR 1.3–7,
callback-based extraction) instead of `rar` 0.4 (MIT, RAR5 only, writes straight to a
destination path, which would bypass `ExtractionSink`). Both are GPLv3-compatible;
`unrar`/RARLAB code is never added.

## 불변식

1. Every extracted file, directory and symlink from split ZIP, 7z and RAR goes through `ExtractionSink` (no third-party crate gets a destination path) → `rar_io.rs` passes only `Box<dyn Write>` sinks to `rars`; `sevenz.rs` uses `for_each_entries` readers; tests `rar_read.rs::zip_slip_*`, `sevenz_pack.rs::*_slip_*`.
2. Unpack never overwrites an existing file when `overwrite: false` → `ExtractionSink::begin_file` `create_new(true)`; tests `rar_read.rs::overwrite_false_*`, `split_archives.rs::overwrite_false_*`.
3. Header-declared sizes never drive unbounded allocation; `SafetyBudget` caps bytes/entries/ratio for every format → `rars` `ArchiveReadOptions` limits + sink budget; tests `rar_read.rs::budget_*`, `sevenz_pack.rs::budget_*`.
4. Pack output is all-or-nothing: on error or cancel no final volume and no `.dandi-*` temp file remains → `SplitVolumeWriter`/`PkwareSplitWriter` `Drop`, `TempFileGuard`; tests `split_archives.rs::cancel_*`.
5. A split set opened from any volume reads the whole set, and a missing middle volume yields `CorruptArchive` naming that file → `split::discover_volumes`; tests `split_archives.rs::missing_*`.
6. PKWARE split ZIPs are spec-valid: `.z01` starts with `0x08074b50`, LFH/CD records and the EOCD trailer never straddle volumes, CD `disk_number_start` and EOCD disk fields match the volume that holds them → `zip/writer.rs` `GoldenZipWriter::Pkware`; tests `split_archives.rs::pkware_layout_*` + eval cross-check with Info-ZIP `zip -s 0`.
7. Split writers never hold more than one volume file handle open → `SplitVolumeWriter` active-handle cache; test `split_archives.rs::many_volumes_*`.
8. 7z entry paths are NFC with `/`, OS junk is excluded by default, password is UTF-8 NFC; with a password the header is encrypted → `sevenz.rs::pack_7z`; tests `sevenz_pack.rs`.
9. No new crate links RARLAB code; all manifests stay `GPL-3.0-only` → license audit step in 검증 방법.
10. CLI and TypeScript hold no archive logic: size strings are parsed by `dandi_core::parse_size_spec`; the GUI only maps choices to a request → `split.rs`, `commands.rs`, `pack.ts`.

## 장애 표

| 상황 | 기대 거동 | 코드 자리 |
|---|---|---|
| Middle volume (`.z02` / `.002` / `.part2.rar`) missing | `CorruptArchive("missing split volume '<path>'")`, nothing extracted | `split::discover_volumes`, `rar_io::open_rar_volumes` |
| Volume truncated mid-entry | structured `CorruptArchive`/`Io`, partial output removed | `SplitFileReader::read` early-EOF error, sink cleanup |
| Cancel mid-pack (split) | `Cancelled`, all staged volumes deleted | `SplitVolumeWriter`/`PkwareSplitWriter` `Drop` |
| Disk error while renaming staged volumes | already-renamed volumes and remaining temps removed | `split::commit_staged_volumes` |
| Re-pack with fewer volumes over an older set | stale higher-numbered volumes removed (overwrite) or `AlreadyExists` (no overwrite) | `split::commit_staged_volumes` |
| Split size < 64 KiB or unparsable size string | `InvalidInput` before any file is created | `split::validate_split_size`, `parse_size_spec` |
| 7z/RAR encrypted, no password | `PasswordRequired` | `sevenz::map_7z_error`, `rar_io::map_rar_error` |
| 7z/RAR wrong password | `InvalidPassword`, partial file removed | same + `StagedFileHandle` `Drop` |
| RAR malformed / parser panic | `CorruptArchive`, no panic escapes | `rar_io::run_rars_guarded`, `catch_unwind` around extraction |
| RAR feature `rars` cannot decode | `UnsupportedFormat` | `rar_io::map_rar_error` |
| RAR hardlink / junction / file-copy entries | `UnsafeSymlink`, not followed | `rar_io` link callback |
| RAR dictionary > 256 MiB | `BudgetExceeded` with reason | `build_rar_read_options` |
| Entry escaping destination (any format) | `UnsafePath`, zero writes outside | `ExtractionSink` |
